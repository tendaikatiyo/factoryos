# Ops Audit Pack

This folder collects raw audit data for model review and human analysis.

What to add:
- `SOPs/`: Markdown files with existing SOPs and raw notes per person/station.
- `floorplans/`: Simple sketches (.svg or .png) showing where stations and machines are.
- `environment_notes/`: Notes about lighting, temperature, noise, hazards, plus photos.
- `machines/`: Machine code dumps, logs, firmware files, and notes.
- `model_review.md`: Instructions and prompts for an advanced model to provide feedback.
- `metadata.json`: High-level metadata about the audit (date, site, contact, scope).

Next steps:
