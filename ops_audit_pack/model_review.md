# Model Review Instructions

Purpose: Provide structured raw data for an advanced model to analyze operational performance and suggest improvements.

Include in each submission:
- Clear `scope` (what area, stations, date range)
- `SOPs/` folder with one md per station/person (include headcount per station)
- `floorplans/` sketches with labels
- `environment_notes/` with photos named `env_<number>.jpg` and short captions
- `machines/` with code dumps or paths to logs

Suggested prompt template for model:

1. Summarize key operations and constraints.
2. Identify bottlenecks and safety risks.
3. Recommend 5 prioritized improvements (impact, effort, quick wins).
4. Flag missing data needed to improve recommendations.

Deliverables: JSON summary + annotated checklist + example action plan.
