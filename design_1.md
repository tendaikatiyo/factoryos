## Typography

Four roles, four families. Do not collapse them.

| Role | Family | CSS utility | Use |
| --- | --- | --- | --- |
| **Display / wordmark** | Stack Sans Notch | `.font-display` | Home hero h1,  |
| **Headings** | Geist Sans | `.font-heading` | Page titles, card titles, , table row labels |
| **Body** | Inter | default / `.font-body` | Paragraphs, nav labels, descriptions, buttons |
| **Data / labels** | Geist Mono | `.font-mono`, `.caption-label` | Table column headers, badges, uppercase field labels |
| **Stats** | Geist Sans + tabular nums | `.font-stat` |  large numbers on cards |
