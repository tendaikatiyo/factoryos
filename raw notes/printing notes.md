there are four printers in the printing section
PR01-PR04 and one laminator (unsure about code)
they recieve plain rolls from extrusion for printing and return printed rolls
if a roll is intended for autopack it usually leaves for the slitting and exits prod
if the roll is intended for bagmaking it proceeds to that station

printing machines usually have multiple operators up to 3
operators are responsible for setting up machines and mixing inks to match specs
they first do a test run ro match the design once design is matched and quality assurance approves they can run the order 
they  have a QA approved attached to the machine for comparison
the printing inks are stored in ink storeroom with controls in place to prevent loss or theft
likewise with the solvents
there is a lithography room there as well for clients that need their own plates

this wing also houses the laminator for jobs that need to two layers of film laminated together 
usually BOPP film and MBOPP film from the laminator the rolls go to the sliting and leave prod
laminated rolls are usually for autopack
printing operators also run the laminator
printers like the rest of the factory operate on two shift basis
